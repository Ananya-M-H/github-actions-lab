# GitHub Actions Lab

A beginner-friendly project to learn GitHub Actions and CI/CD.

## Project Description

A simple Task Manager application built using Node.js.

## Features

- Add tasks
- Retrieve all tasks
- Mark tasks as completed
- Validate task inputs

## Technologies

- JavaScript
- Node.js
- GitHub Actions

## CI/CD Workflow

The GitHub Actions workflow automatically:

1. Checks out the repository.
2. Sets up Node.js.
3. Checks the Node.js version.
4. Runs automated tests.

The workflow is triggered on pushes and pull requests targeting the main branch.

## Run Locally

```bash
npm test

```
